Appointment State Machine

Strict, unidirectional workflow enforced by both Backend APIs and React UI logic.

BOOKED
Admin, Recep

Initial State. Doctor UI hides action buttons.

➔ check-in
CHECKED_IN
Admin, Recep

Patient arrived. Control hands over to medical staff.

➔ complete
COMPLETED
Admin, Recep, Doctor

Terminal State. Notes can now be added.

CANCELLED

Can only occur from BOOKED

NO_SHOW

Auto-assigned by chron/fetch if passed

Core Slot Generation Logic (Conceptual)

// 1. Generate base slots from Doctor's Availability Shifts
let available = generateSlots(shift.start, shift.end);

// 2. Filter out slots outside Clinic Working Hours
available = available.filter(slot => slot >= clinic.start && slot < clinic.end);

// 3. Remove slots colliding with Doctor Breaks & Holidays
available = available.filter(slot => !breakSlots.includes(slot));

// 4. Remove already BOOKED/CHECKED_IN/COMPLETED appointments
available = available.filter(slot => !bookedAppointments.includes(slot));

return available;
